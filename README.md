# XFOOD Store — редизайн

Внутренний магазин мерча команды XFOOD, собранный заново в пластике референсов:
[«Альтернатива»](https://anyboom.github.io/alt/) и [Dodo Brands](https://dodobrands.io/).
Кремовый фон, крупный гротеск Onest, скруглённые панели, пилюли и большие воздушные отступы.

## Что внутри

- Одностраничная витрина: герой → коллекция «Осень 26» → каталог из 15 позиций →
  «Как потратить» → «Как заработать» → финальный CTA → футер.
- Фильтры каталога (Всё / Одежда / Аксессуары / Другое) с подсветкой активного чипа.
- Выбор размера/цвета чипами прямо в карточке: активный чип подсвечивается, CTA
  показывает выбор («Проверить: M»). Низ карточки закреплён (цена, варианты, кнопка) —
  элементы не скачут от карточки к карточке при разной длине названий.
- Reveal-анимации при скролле.
- Ванильные HTML/CSS/JS — без фреймворков и сборки, как на референсе.

## Быстрый старт

Статика, сборка не нужна:

```bash
# просто открыть index.html в браузере
# или поднять локальный сервер
python3 -m http.server 8080
```

## Структура

```
index.html            # разметка страницы (RU, семантические теги)
css/style.css         # дизайн-токены + стили, вся система в :root
js/main.js            # меню, фильтры, выбор размера, reveal (IIFE, без глобалов)
assets/products/      # 15 фото товаров (webp, скачаны с xfoodstore.ru)
assets/collections/   # баннер коллекции «Осень 26»
assets/favicon-xfood.png
```

## Дизайн-решения (почему так)

- **Палитра «тёплый томат»**: крем `#f6f0e6` + томатный акцент `#c74a1e` + тёмный
  шоколад `#2b1710` в баннерах. Выбрана пользователем из двух вариантов; томат
  поддерживает «пиццерную» природу бренда и оранжевый термос из коллекции.
  Кнопочный томат `#c74a1e` даёт контраст с белым текстом ≈ 4.75:1 (WCAG AA),
  декоративный `#e35f2d` используется только для крупных цифр и мелкой графики.
- **Цвета в hex, не в oklch**: референс (alt) использует hex-токены — редизайн
  сохраняет ту же систему, чтобы стили оставались переносимыми между проектами.
- **Фото товаров на всю площадь карточки (`object-fit: cover`)**: исходники
  разноформатные (от 9:16 до 3:2), cover заполняет медиаблок целиком; пшеничный
  тинт остаётся подложкой на момент загрузки. Центр-кроп держит товар в кадре —
  студийные съёмки XFOOD центрированы.
- **Большие пространства**: секционный ритм `clamp(3rem, 9vh, 6rem)` против
  `4rem` у референса — воздух задан шире по запросу.
- **Зерно** (`.grain`, opacity 0.045): тонкая SVG-плёнка поверх страницы снимает
  цифровую стерильность; отключается в print и не влияет на ввод.
- **Движение**: только `transform`/`opacity` (reveal, hover-подъём карточек), всё уважает
  `prefers-reduced-motion`; hover-эффекты спрятаны в `@media (hover: hover)`.

## Прототипные ссылки (где подключить бэкенд)

| Элемент | Сейчас | В продакшене |
|---|---|---|
| «Войти» (шапка, меню) | Telegram-инвайт команды | Telegram-авторизация витрины |
| «Корзина» (шапка) | `#how` | корзина авторизованного пользователя |
| «Проверить остаток →» на карточках | `#how` | проверка остатка по размеру/цвету |
| «Telegram» / «VK» | реальные ссылки сообщества | без изменений |

Тексты и цены (`D …`) взяты с действующего xfoodstore.ru без изменений.
Версия фронта поднята до **1.44** (было 1.43).

## Доступность

- Семантические `header/nav/main/section/footer`, якорная навигация.
- `aria-pressed` на фильтрах, `aria-expanded` на меню, alt-тексты на всех фото.
- Видимые `:focus-visible` состояния (светлые на тёмных панелях).
- Касательные цели ≥ 44px, контраст текста ≥ 4.5:1 (кроме декоративной графики).
